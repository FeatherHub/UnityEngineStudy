Android 

NativeActivity의 치명적 결함
IME(소프트 키보드) 지원이 없다

it doesn't have built-in support for input methods (such as onscreen keyboards)
so it's often not a good choice for applications that need to support text input

---

구식 — Activity
Activity was originally the only application entry point that Unity supported

public class UnityPlayerActivity extends Activity   // NativeActivity 아님

이 구현체들은 전부 libunity.so 안에

---

신형 — GameActivity
Previously NativeActivity was the recommended class for games
GameActivity replaces it as the recommended class for games

GameTextInput 내장(IME 해결)
AppCompatActivity 파생이라 Jetpack 컴포넌트 사용 가능
SurfaceView로 렌더해서 다른 UI와 섞기 쉬움
입력이 android_input_buffer 기반 새 구현(NativeActivity의 InputQueue와 별개).

---

GameActivity 층    libgame.so   가 주인,  libunity.so  가 손님
GameActivity니까 game

IL2CPP 층          libunity.so  가 주인,  libil2cpp.so 가 손님

---

구형

[1] ART  →  UnityPlayerActivity.onCreate            extends Activity

[2] new UnityPlayerForActivityOrService

[3] UnityPlayer::loadNative
      System.load(nativeLibraryDir + "/libmain.so")

[5] dlopen libunity.so

---

신형

━━━ 진입 축 ━━━                                        ━━━ 로더 축 ━━━

[1] ART → UnityPlayerGameActivity
      extends GameActivity extends AppCompatActivity

[2] static { System.loadLibrary("game") }
      → libgame.so dlopen
      → game-activity 쪽 JNI_OnLoad

[4] onCreateSurfaceView
      → new UnityPlayerForGameActivity(...)
                                                      [5] UnityPlayer::loadNative
                                                            → libmain.so 로드

                                                      [6] dlopen libunity.so

[8] native thread 에서 android_main(app)   
  → MainLoop(app)

[9] UnityApplication::CreateInstance(app)
      dlopen("libunity.so", RTLD_LAZY)   
      AttachCurrentThread(...) //native thread 를 JVM 에 붙임
      libunity.so 가 GAToUnity 함수 포인터를 채운다

[10] instance->Loop()

[11] 매 프레임  ProcessFrame() → LoopRuntime()

---

④  OS          ──android_main──────────▶  libgame.so

⑥  libgame.so  ──LoopRuntime()─────────▶  libunity.so
