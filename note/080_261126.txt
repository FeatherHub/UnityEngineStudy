---

OnAdRewarded
network가 보상 조건을 채웠다고 판정함 (예: 영상 끝까지 시청)
network의 보상 로직

---

OnAdClosed
광고 화면 dismiss
화면 lifecycle (사용자 조작)

---

Unity Ads: 광고가 끝날 때 onUnityAdsShowComplete(placementId, state) 하나만 오고, 
state가 COMPLETED인지로 보상 여부를 알려 준다. 

이걸 LevelPlay의 Rewarded와 Closed 두 event로 나눠 올릴 때 
어떤 순서로 보낼지는 adapter 구현이 정한다

mediation은 이런 network 20여 개를 한 API로 묶는다
그러니 순서를 하나로 보장할 수 없고, 

그래서 문서도 "asynchronous"라고만 하고 
순서를 약속하지 않는다.

---

Google.VersionHandler

---

UpmLevelPlaySdkInstaller

Package Manager의 registeredPackages event를 구독
LevelPlay 패키지가 추가되거나 버전이 바뀌면 다음 코드가 실행된다

await m_SdkInstaller.PreInstallAsync();                 // 원격 LevelPlayVersions.json 받기

await m_SdkInstaller.InstallLatestIronSourceSdkAsync(); // native SDK의 xml

await m_SdkInstaller.InstallUnityAdsAdapterAsync();     // Unity Ads adapter의 xml

---

[Package Manager]   add com.unity.services.levelplay
        │  registeredPackages event
[Network Manager]   versions JSON → *Dependencies.xml → Assets/LevelPlay/Editor/
        │
[MDR resolver]      xml → mainTemplate.gradle (Android) / Podfile (iOS)
        │
[Unity build]       export Gradle / Xcode project → post-process Manifest, Info.plist
        │
[Gradle/CocoaPods]  download .aar / pods (+ transitive Unity Ads SDK) → link → AAB / IPA
