에디터 미리보기

타일 구현에 "지금 에디터 미리보기 중인가" 분기를 넣게 할 수는 없다
ITilemap이 그 분기를 대신 흡수한다
타일은 그냥 `GetTile(pos)`을 부르고, 문맥에 맞는 답이 돌아온다

브러시를 타일맵 위에 올리면 클릭 전에도 결과가 미리 보이는데, 
이 미리보기 타일들은 진짜 Tilemap 데이터가 아니라 별도의 preview 레이어에 있다

---

Grid — "셀 하나가 어떤 모양이고 얼마나 큰가"만 정한다
Tilemap — "(3, 5) 칸에 어떤 타일이 있는가"를 저장한다

둘 다 GridLayout을 상속해서 CellToWorld() / WorldToCell()을 갖는데, 
Grid는 좌표 변환만 하고 
Tilemap은 거기에 저장소가 붙은 형태

---

왜 나눴나? 
한 좌표계 위에 여러 데이터 레이어를 얹으려고

Grid  (Cell Size 1×1, Layout: Rectangle)      ← 좌표계는 하나
├── Tilemap "Background"                       Order in Layer 0
├── Tilemap "Ground"  + TilemapCollider2D      Order in Layer 1, 충돌 담당
├── Tilemap "Water"   + TilemapCollider2D      Order in Layer 2
└── Tilemap "Decoration"                       Order in Layer 3

지형과 장식을 분리해서 정렬 순서와 충돌을 따로 주려면 
Tilemap이 여러 개여야 하는데, 

좌표계까지 여러 개면 정렬이 어긋나. 
그래서 좌표는 Grid에 한 번만 두는 거야
